Technique

Zero-shot Prompting

Give the model a task with no examples. Fast, but limited on complex tasks.

GSM8K Accuracy 78%
Token Cost 1×
Best For Simple Tasks
Complexity Minimal

Key Insight

Zero-shot works for simple tasks like fact recall. For multi-step problems, the model must compress all reasoning into hidden states — and that limits accuracy.

When to Use

Simple factual questions, one-step classification, or when you can't provide good examples. Not for math or multi-step reasoning.

关键术语 / Key Terms

Few-shot Prompting / 少量样本提示词
在提示词中包含输入-输出演示，以锚定模型的输出格式和行为
Chain-of-Thought (CoT) / 链式思维
引出中间推理token，延伸模型的有效计算深度
Self-Consistency / 自洽性
采样N条推理路径，通过多数票选择最常见答案
Tree-of-Thought (ToT) / 树状思维
对推理分支进行结构化搜索，评估并剪枝低分路径
ReAct / 推理+行动
在思考-行动-观察循环中将推理与外部工具交错
Zero-shot CoT / 零样本链式思维
附加"让我们逐步思考"触发短语，无需示例

Key Takeaways

  • Examples anchor format better than instructions
  • CoT extends effective computation depth
  • Self-consistency trades cost for reliability
