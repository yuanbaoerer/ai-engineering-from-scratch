LoRA & QLoRA 微调

全量微调 7B 模型需要 56GB 显存。你没有。大多数公司也没有。LoRA 让你在 6GB 显存内微调同一个模型——训练不到 1% 的参数。

// CONCEPT

全量微调的成本问题

Llama 3 8B 有 80 亿参数。fp16 下每个参数 2 字节，仅加载权重就要 16GB。加上梯度、优化器状态和激活值——总计约 56GB 显存。

显存需求 56 GB
可训练参数 100%
适用场景 —
显存 (7B) 56 GB

核心洞察

全量微调更新模型中的每一个权重。这不仅昂贵，还会导致灾难性遗忘——模型在你的任务上变好，在其他所有任务上变差。

何时使用

当你需要模型采用特定风格、格式或推理模式，且无法通过提示词实现时。当你需要一致的结构化输出。当你需要将大模型蒸馏到小模型。

自测题

LoRA 通过什么方式减少可训练参数？

关键术语

LoRA / 低秩适应
冻结基础权重，训练两个小矩阵 A 和 B，其乘积近似完整的权重更新
QLoRA / 量化低秩适应
将基础模型以 4-bit NF4 加载，在其上以 fp16 训练 LoRA 适配器，使 7B 微调仅需 6GB 显存
秩 (r)
矩阵 A 和 B 的内部维度，控制表达能力与参数量的平衡
Alpha (α)
缩放因子，α/r 缩放适配对最终输出的贡献
NF4
Normal Float 4-bit：一种 4-bit 数据类型，量化级别位于正态分布分位数处
适配器 (Adapter)
保存为独立文件（10-100MB）的 LoRA A 和 B 矩阵，可加载到基础模型之上

关键要点

  • LoRA 训练 0.78% 的参数，获得 95-100% 的质量
  • QLoRA 将 7B 微调的显存需求从 56GB 降到 6GB
