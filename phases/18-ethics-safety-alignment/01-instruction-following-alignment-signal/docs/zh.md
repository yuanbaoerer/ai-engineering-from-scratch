# 指令跟随作为对齐信号

> 每一个后来对RLHF的批评都是针对这个流水线。在你研究优化压力如何扭曲代理之前，你必须先看到代理本身。InstructGPT（Ouyang et al., 2022）定义了参考架构：在指令-响应对上进行监督微调，基于成对偏好排名训练奖励模型，以及使用PPO对奖励模型进行优化，同时通过KL惩罚项约束到SFT策略。1.3B参数的InstructGPT比175B参数的GPT-3更受偏好。这个单一结果是2026年每个前沿实验室仍然使用RLHF形状后训练流水线的原因。

**类型：** 学习
**语言：** Python（标准库，玩具三阶段流水线）
**前置条件：** 阶段10 · 06（SFT），阶段10 · 07（RLHF），阶段10 · 08（DPO）
**时间：** ~45分钟

## 学习目标

- 描述InstructGPT流水线的三个阶段及其各自使用的损失函数。
- 解释为什么1.3B参数的指令微调模型在人类偏好评估中击败了原始的175B参数GPT-3。
- 说明阶段3中的KL惩罚项防止了什么，以及为什么移除它会导致模式寻求行为。
- 描述对齐税（Alignment Tax）和Ouyang等人使用的PPO-ptx缓解方法。

## 问题

预训练的语言模型是补全文本的，而不是回答问题。向GPT-3提问"写一个反转列表的Python函数"，你经常得到另一个提示词，因为训练分布中的大部分是继续生成更多网页文本。模型在做它的工作——但这个工作是错误的。

每个严肃实验室用来解决这个问题的代理是人类偏好。两个补全结果交给评估者；评估者选择更好的那个；一个奖励模型学习评估者的偏好。然后一个强化学习循环将策略向奖励模型高分输出的方向移动。这就是完整的InstructGPT论点，三句话说完。论文的其余部分都是工程。

## 概念

### 阶段1：监督微调（SFT）

收集提示-响应对，其中响应是善意人类会写出的内容。Ouyang等人使用了来自标注者和OpenAI API的13k个提示词。在这些数据上使用标准交叉熵损失微调基础模型。

SFT给你的是：模型现在回答问题而不是继续提问。它没有给你的是：当多个答案都合理时，评估者偏好哪个答案的信号。

### 阶段2：奖励模型（RM）

对于每个提示词，从SFT模型中采样K个补全结果。标注者对它们进行排名。训练一个奖励模型，对任何提示-响应对进行评分，使得对于`y_w`比`y_l`更受偏好的配对：

```
L_RM = -log sigmoid(r(x, y_w) - r(x, y_l))
```

这是Bradley-Terry成对偏好损失。RM通常从SFT模型初始化，将语言模型头替换为标量头。

奖励模型很小：6B参数对于175B的InstructGPT就足够了。它们也很脆弱——论文的第5节主要讨论了在小规模上出现的奖励黑客行为。

### 阶段3：带KL惩罚的PPO

定义目标函数：

```
J(pi) = E_{x~D, y~pi(.|x)} [ r(x, y) ] - beta * KL(pi(.|x) || pi_SFT(.|x))
```

使用PPO最大化。KL项防止`pi`偏离SFT策略太远。没有它，优化器会找到对抗样本——那些因为RM从未见过它们而获得高分的字符串，而不是因为人类真正偏好它们。

KL系数`beta`是RLHF中最重要的单一超参数。太低：奖励黑客。太高：没有比SFT改进。

### 对齐税

经过RLHF后，模型更受人类偏好，但在标准基准测试（SQuAD、HellaSwag、DROP）上性能下降。Ouyang等人称之为对齐税（Alignment Tax），并使用PPO-ptx修复：将预训练梯度混入RL目标，这样模型不会忘记它从未被奖励过的下游任务。

```
J_ptx(pi) = J(pi) + gamma * E_{x~D_pretrain} [ log pi(x) ]
```

PPO-ptx成为了标准。Anthropic、DeepMind和Meta都使用某种变体。

### 结果

一个1.3B参数的InstructGPT（SFT + RM + PPO-ptx）在约70%的情况下比175B参数的基础GPT-3更受标注者偏好。在来自生产流量的隐藏测试提示词上，差距更大。从这个数字可以读出两点：

1. 对齐是与能力不同的维度。175B模型有更多能力；1.3B模型有更多对齐；标注者偏好对齐的那个。
2. 能力下限由基础模型设定。你无法通过RLHF让基础模型知道它从未见过的事实。

### 为什么这是阶段18的参考点

后续课程中的每个批评——奖励黑客（第2课）、DPO（第3课）、谄媚（第4课）、CAI（第5课）、睡眠代理（第7课）、对齐伪装（第9课）——都是针对这个流水线的某些部分。奖励黑客攻击阶段2。DPO合并阶段2和3。CAI替换人类标注者。谄媚表明标注者是有偏见的信号。对齐伪装表明策略可以完全绕过阶段3。在你理解整个流水线之前，你无法理解这些批评中的任何一个。

## 使用它

`code/main.py`在玩具偏好数据上模拟三个阶段。基础"策略"是一个偏向动作{A, B, C}的硬币。阶段1 SFT模仿标注者在200个提示词上的行为。阶段2从500个成对排名中拟合Bradley-Terry奖励模型。阶段3运行简化的PPO更新，带有KL惩罚项约束到SFT策略。你可以观察奖励上升、KL散度增长和策略漂移——你可以关闭KL项来观察奖励黑客在50步更新内出现。

观察点：

- `beta = 0.1`与`beta = 0.0`时的奖励轨迹。
- 训练步骤中KL(pi || pi_SFT)的变化。
- 最终动作分布与标注者偏好的比较。

## 交付它

本课产出`outputs/skill-instructgpt-explainer.md`。给定一个RLHF流水线描述或论文摘要，它识别三个阶段中哪个被修改，每个阶段使用的损失函数，以及是否存在KL惩罚或等效的正则化器。

3. 阅读Ouyang et al.（arXiv:2203.02155）图1。通过运行1、5、20、100步PPO并测量与SFT模型的偏好，重现标注者偏好曲线。

4. 论文的第4.3节报告1.3B InstructGPT在约70%的情况下击败175B GPT-3。为什么在隐藏的生产提示词上的比率比标注者自己的提示词上更高？

## 关键术语

| 术语 | 人们怎么称呼它 | 它实际意味着什么 |
|------|-----------------|------------------------|
| SFT | "指令微调" | 阶段1：在提示-响应对上的交叉熵微调 |
| 奖励模型 | "RM" | 在（提示，响应）上的标量回归器，使用Bradley-Terry在成对标签上训练 |
| Bradley-Terry | "成对偏好损失" | -log sigmoid(r_w - r_l)；将成对排名简化为二分类 |
| KL惩罚 | "正则化器" | `beta * KL(pi \|\| pi_SFT)`——保持RL策略接近SFT锚点 |
| PPO-ptx | "带预训练混合的PPO" | 将预训练对数似然的一部分添加到PPO目标中以抵消对齐税 |
| 对齐税 | "RLHF退化" | RLHF后在标准基准测试上的下降，RLHF并未针对这些测试 |
| 标注者偏好 | "真实标签" | 人类排名的样本；RM是其统计代理，而非"人类价值观"的代理 |
