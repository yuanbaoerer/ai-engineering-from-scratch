# 大语言模型的差分隐私

> DP-SGD 仍然是标准方法——噪声注入梯度更新提供形式化的 (ε, δ) 保证。在计算、内存和效用方面的开销很大；参数高效的 DP 微调（LoRA + DP-SGD）是 2025 年的常见配置（ACM 2025）。两组相互矛盾的证据：基于金丝雀（Canary）的成员推断（Duan 等人，2024）报告对语言模型的成功率有限；训练数据提取（Carlini 等人，2021；Nasr 等人，2025）恢复了大量的逐字记忆。解决方案（arXiv:2503.06808，2025 年 3 月）：差异在于测量的对象——插入的金丝雀 vs "最可提取"的数据。新的金丝雀设计使得无需影子模型即可进行基于损失的成员推断（MIA），并首次对在真实数据上以现实 DP 保证训练的大语言模型进行有意义的 DP 审计。替代方案：PMixED（arXiv:2403.15638）——通过在下一个词元分布上使用专家混合（Mixture of Experts）在推理时进行私有预测；DP 合成数据生成（Google Research 2024）。新兴攻击：通过大语言模型反馈的差分隐私反转（Differential Privacy Reversal via LLM Feedback）——置信度分数泄露。

## 学习目标

- 定义 (ε, δ)-差分隐私（Differential Privacy）并陈述 DP-SGD 的方法。

## 问题背景

大语言模型会记忆。Carlini 等人 2021 年表明，生产级语言模型可以按需逐字复现训练文本。差分隐私是形式化的防御手段：训练使得输出对任何单个训练样本的不敏感性可证明地成立。2024-2025 年的证据表明 DP-SGD 是必要的，但部署的 ε 值可能与威胁模型不匹配。

## 核心概念

### (ε, δ)-差分隐私

一个随机化算法 M 是 (ε, δ)-DP 的，如果对于任何相差一个样本的两个数据集和任何事件 S：
P(M(D) in S) <= e^ε * P(M(D') in S) + δ。

解释：输出分布足够接近（由 ε 参数化），以至于任何单个个体的贡献无法被可靠地推断，除了以概率 δ 的例外情况。

### DP-SGD

Abadi 等人 2016。标准方法：
1. 采样一个迷你批次（Mini-batch）。
2. 计算每个样本的梯度。
3. 将每个样本的梯度裁剪到阈值 C。
4. 求和裁剪后的梯度并添加标准差为 σ * C 的高斯噪声。
5. 使用带噪声的和来更新参数。

隐私成本由记账器（Accountant）跟踪（矩记账器、Rényi DP 记账器）。大语言模型文献中报告的 ε 值因威胁模型、数据敏感性和效用目标而异；没有普遍"安全"的默认 ε。已发表的示例在某些大语言模型训练设置中大约为 ε ≈ 1-10，但这些是说明性的——不是推荐的默认值。较低的 ε 通常需要更多噪声，可能增加效用损失。

### LoRA + DP-SGD

对前沿模型进行完整的 DP-SGD 是不可行的。LoRA（Hu 等人 2022）将梯度更新限制在小型适配器上，减少了每个样本的梯度存储。LoRA + DP-SGD 是 2025 年的常见配置。DP 保证适用于适配器；基础模型保持固定。

### 2024-2025 年的矛盾

两组证据：

- **基于金丝雀的成员推断（Duan 等人 2024）。** 在训练数据中插入独特的金丝雀，测量成员推断攻击者是否能识别它们。报告对语言模型的成功率有限。表明成员推断很难。
- **训练数据提取（Carlini 2021，Nasr 等人 2025）。** 用前缀提示模型；测量它是否能从训练中恢复逐字文本。报告了大量的记忆。表明成员推断在相关意义上是容易的。

2025 年 3 月的解决方案（arXiv:2503.06808）：两者测量的是不同的东西。成员推断在插入的金丝雀上问"样本 e 是否在 D 中？"提取问"我能从 D 中恢复什么？""最可提取"的样本对隐私很重要；金丝雀低估了这一点，因为它们不是为可提取性而优化的。

新的金丝雀设计。无需影子模型的基于损失的成员推断。首次对在真实数据上以现实 DP 保证训练的大语言模型进行有意义的 DP 审计。

### DP 训练的替代方案

- **PMixED（arXiv:2403.15638）。** 推理时的私有预测。在下一个词元分布上使用专家混合；每个专家看到训练数据的一个分片；聚合添加噪声以实现 DP。完全避免 DP 训练。
- **DP 合成数据生成（Google Research 2024）。** 使用 DP-SGD 进行 LoRA 微调，采样合成数据，在合成数据上训练下游分类器。

两者都以不同的威胁模型为代价，规避了完整 DP 训练的效用成本。

### 通过大语言模型反馈的差分隐私反转

2025 年的新兴攻击。使用 DP 训练模型的置信度分数作为预言机来重新识别个体。即使输出不泄露，置信度分布也可能泄露。

防御措施：不暴露置信度，或在暴露前截断/量化它们。这是 (ε, δ)-DP 训练之外的额外要求。

## 实践

`code/main.py` 在一个玩具二分类数据集上模拟 DP-SGD。你可以调整噪声乘数 σ 和裁剪范数 C，跟踪 (ε, δ) 预算和准确率损失。一个"金丝雀攻击"插入一个独特的训练样本，测量对数损失测试在 DP 前后是否能检测到它。

## 交付

本课程产出 `outputs/skill-dp-audit.md`。给定一个对大语言模型部署的 DP 声明，它审计：(ε, δ) 值、使用的记账器、成员推断评估协议，以及置信度暴露向量是否已被评估。

## 练习

1. 运行 `code/main.py`。扫描 σ ∈ {0.5, 1.0, 2.0} 并报告 (ε, δ)-准确率权衡。识别效用崩溃的临界点。

2. 实现金丝雀插入和对数损失测试。在 σ = 1.0 时测量 DP-SGD 前后的检测率。

3. 阅读 Nasr 等人 2025 关于训练数据提取的内容。为什么在中等 ε 下提取成功率不会崩溃？这对成员推断作为评估手段意味着什么？

4. 设计一个使用 PMixED（arXiv:2403.15638）的部署方案，完全在推理时运行。PMixED 解决的威胁模型是什么，是 DP-SGD 没有解决的？

5. 描述通过大语言模型反馈的差分隐私反转攻击。设计一种限制置信度分数泄露的对策并估计其部署成本。

## 关键术语

| 术语 | 通俗说法 | 实际含义 |
|------|---------|---------|
| DP（差分隐私） | "(ε, δ)-差分隐私" | 形式化隐私：在相邻数据集变化下输出分布接近 |
| DP-SGD | "噪声注入 SGD" | 梯度裁剪 + 高斯噪声添加；标准 DP 训练 |
| LoRA + DP-SGD | "高效私有微调" | 在低秩适配器上的 DP-SGD；2025 年标准配置 |
| MIA（成员推断） | "成员推断" | 确定某个样本是否在训练数据中的攻击 |
| 金丝雀（Canary） | "插入的水印样本" | 用于测量 DP 泄露的独特训练样本 |
| PMixED | "私有推理混合" | 通过下一个词元分布上的专家混合实现实时 DP |
| DP 反转 | "置信度泄露攻击" | 使用模型置信度作为预言机进行重新识别的攻击 |
