# MDP 与强化学习基础

> 日期: 2026-06-22

## 1. MDP 五元组

马尔可夫决策过程由五个对象组成，是一切 RL 算法的数学基础：

| 对象 | 符号 | 含义 |
|------|------|------|
| 状态 | S | 智能体观察到的所有信息 |
| 动作 | A | 智能体可选的操作 |
| 转移 | P(s'\|s,a) | 给定状态和动作后，下一个状态的概率分布 |
| 奖励 | R(s,a,s') | 每一步的标量反馈信号 |
| 折扣 | γ | 衡量未来奖励的重要性，γ=0.99 对应约 100 步视野 |

**马尔可夫性质：** 未来只依赖当前状态，不依赖历史。如果不够用，说明状态设计有问题。

## 2. 贝尔曼方程

核心思想：**把"长期回报"拆成"当前一步 + 剩下的"**。

```
V(s) = r + γ × V(s')
```

- V(s) = 从状态 s 出发，最终能拿多少总奖励
- r = 这一步立即拿到的奖励
- γ = 折扣因子
- V(s') = 下一个状态的价值

本质是递归分解，可以反复迭代展开为 `V(s) = r₁ + γ(r₂ + γ(r₃ + ...))`。所有 RL 算法（DQN、PPO、Q-learning）都建立在这个分解之上。

## 3. RL 不只是设计 MDP + 训练

设计 MDP 是**定义问题**（前提），训练是**解决问题**（占 90% 工作量）。训练的难点在于：

- **不知道转移概率 P** — 只能从交互中采样
- **不知道最优解** — 不能枚举所有状态
- **奖励可能稀疏** — 赢了才给 +1，中间几百步都是 0

## 4. RL 算法的四大类别

| 类别 | 代表方法 | 核心思路 |
|------|----------|----------|
| 基于值 | Q-learning, DQN | 学 Q(s,a) 表，间接得到策略 |
| 基于策略 | REINFORCE, PPO | 直接优化策略网络 π(a\|s) |
| Actor-Critic | A2C, SAC, TD3 | 值函数 + 策略联合学习 |
| Model-based | MuZero, Dreamer | 额外学世界模型，用它规划 |

按是否学环境模型分：Model-free（PPO、DQN）vs Model-based（MuZero、Dreamer）。

## 5. LLM 领域的 RL 方法

| 方法 | 特点 |
|------|------|
| GRPO | DeepSeek 提出，PPO 简化版，去掉 critic 网络 |
| DPO | 直接从偏好数据学策略，跳过奖励模型 |
| RLHF | PPO + 奖励模型 + KL 约束的组合 |
| REINFORCE++ | 简化 REINFORCE + 稳定性技巧 |

## 6. 折扣因子 γ 的直觉

有效视野 ≈ `1/(1-γ)`：

| γ | 有效视野 |
|---|---------|
| 0.9 | ~10 步 |
| 0.99 | ~100 步 |
| 0.999 | ~1000 步 |

- 太低 → 智能体短视，只看眼前
- 太高 → 信用分配嘈杂，许多步骤要为遥远未来负责
- 无限视野任务不能用 γ=1，否则价值无穷大

## 7. 策略、价值与 Q 值的关系

- **策略 π(a|s)** — 状态到动作分布的映射
- **价值 V^π(s)** — 在策略 π 下从 s 出发的期望总回报
- **Q 值 Q^π(s,a)** — 在策略 π 下从 s 出发、选动作 a 的期望总回报

每个 RL 算法都会估计 V 或 Q 其中之一，然后据此改进策略。

## 8. 实践中的关键陷阱

- **非马尔可夫状态** — 需要堆叠帧或循环状态来修复
- **稀疏奖励** — 需要奖励塑形或模仿学习自举
- **奖励黑客** — 优化代理奖励产生病态行为（如赛艇绕圈不冲线）
- **奖励尺度** — {+100, -100} 和 {+1, -1} 策略相同但梯度不同，需归一化
