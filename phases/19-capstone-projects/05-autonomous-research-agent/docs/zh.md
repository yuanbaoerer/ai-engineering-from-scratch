# Capstone 05 — 自主研究智能体（AI 科学家级别）

> Sakana 的 AI-Scientist-v2 发表了完整论文。Agent Laboratory 运行了实验。Allen AI 共享了追踪记录。2026 年的形态是实验的规划-执行-验证树搜索，预算成本，沙箱化代码执行，视觉反馈的 LaTeX 写作器，以及自动化的 NeurIPS 风格审稿委员会。本毕业项目要求你构建一个，在每篇论文 30 美元预算内端到端运行，并通过 Sakana 记录的沙箱逃逸红队测试。

**类型：** 毕业项目  
**语言：** Python（智能体 + 沙箱），LaTeX（输出）  
**前置要求：** 第 2 阶段（机器学习），第 3 阶段（深度学习），第 7 阶段（transformers），第 10 阶段（从零构建 LLM），第 14 阶段（智能体），第 15 阶段（自主系统），第 16 阶段（多智能体），第 18 阶段（安全）  
**涉及阶段：** P0 · P2 · P3 · P7 · P10 · P14 · P15 · P16 · P18  
**时间：** 40 小时

## 问题

自主研究智能体在 2026 年跨越了一个门槛。Sakana AI 的 AI-Scientist-v2 在 Nature 上发表，生成的论文通过了研讨会同行评审。ShinkaEvolve（ICLR 2026）将这条线扩展到假设演化。AMD 的 Agent Laboratory 发布了可复现的追踪记录。这些智能体不是魔法——它们是在候选实验树上运行的规划-执行-验证循环，有成本上限、种子绑定沙箱和自动化评审。技艺在于循环、预算和安全故事。

你通过在一个狭窄领域（例如，1 亿参数 transformer 上的注意力稀疏性消融）中实现一个针对种子想法的智能体来学习这个循环。价值不在于第一次运行就发现新东西。价值在于基础设施：树搜索、实验沙箱、写作-评审循环、红队报告。Sakana 团队记录了沙箱逃逸故障；你的智能体必须通过相同的红队测试。

## 概念

智能体是一个最佳优先树搜索。节点是实验规范：（假设、配置、代码、预期结果）。扩展步骤通过小编辑提出子节点（交换优化器、调整批量大小、消融组件）。每个子节点在具有硬资源上限的新沙箱中运行。结果反馈到一个评分函数，该函数按（新颖性 × 质量 × 剩余预算）对节点进行排名。树增长直到预算耗尽，然后最佳分支被写成论文。

写作器是多模态的。它生成 LaTeX 草稿，编译，渲染图形，并将渲染后的 PDF 反馈到 Claude Opus 4.7 的视觉模式，以对布局、图形可读性和声明-证据对齐进行批评。一个由五位 LLM 评委组成的审稿委员会发出 NeurIPS 风格的分数（新颖性、严谨性、清晰度、可重复性、影响力）；如果平均分低于阈值，论文会返回给写作器并附上批评意见。

安全是承载负荷的。每个实验都在 E2B 或 Daytona 沙箱中运行，没有网络出站，有界墙钟时间，以及固定的资源限制。智能体的代码生成步骤通过一个策略层，该层阻止逃逸沙箱的系统调用。红队报告重现了 Sakana 记录的攻击面（fork 炸弹、文件系统逃逸、LLM 编写的网络调用）。

## 技术栈

- 编排：LangGraph，带检查点和人工审批门控
- 树搜索：自定义最佳优先搜索实验节点（来自 Sakana v2 的 AB-MCTS 风格）
- 沙箱：每个实验一个 E2B，Docker-in-Docker 回退；通过 cgroups 设置资源上限
- 文献：Semantic Scholar Graph API + OpenAlex + 本地 FAISS 摘要缓存
- 写作器：LaTeX 模板 + Claude Opus 4.7（视觉模式）用于图形批评和布局
- 审稿委员会：5 位评委（Opus 4.7、GPT-5.4、Gemini 3 Pro、DeepSeek R1、Qwen3-Max）加权聚合
- 实验框架：PyTorch 2.5 用于物理实验，W&B 用于日志记录
- 可观测性：Langfuse 用于智能体追踪，每篇论文 30 美元硬预算

## 构建它

1. **种子和领域界定。** 获取种子想法（例如，"研究小于 1B transformer 注意力图中的稀疏性模式"）。定义搜索空间：模型、数据集、计算预算。

2. **文献检索。** 查询 Semantic Scholar + OpenAlex 获取 50 篇引用最多的相关论文；在本地缓存摘要；生成 1 页领域摘要。

3. **树脚手架。** 用种子假设初始化根节点。实现 `expand(node) -> children`，使用小编辑建议（每个子节点一个配置更改）。实现 `score(node)` 为新颖性 × 质量 × 预算的加权项。

4. **沙箱封装。** 每个实验运行 `docker run --network=none --memory=8g --cpus=2 --pids-limit=256 --read-only`（或等效的 E2B 策略）。种子写入沙箱；输出以只读方式挂载出来。

5. **规划-执行-验证循环。** `plan` 提出子节点。`execute` 运行沙箱，捕获日志和指标。`verify` 对指标运行单元检查（损失是否下降？消融是否隔离了效果？）。失败节点在树上存储失败原因。

6. **写作器。** 预算耗尽后，选择最佳分支。用 matplotlib 渲染图形。通过 Claude Opus 4.7 生成 LaTeX 草稿，将分支追踪放在上下文中。编译。将编译后的 PDF 反馈给 Opus 4.7 视觉进行批评。迭代。

7. **审稿委员会。** 五位评委根据 NeurIPS 风格的评分标准对草稿进行评分（新颖性、严谨性、清晰度、可重复性、影响力）。如果平均分 < 4.0/5，返回给写作器并附上批评意见。3 次重写后硬停止。

8. **红队测试。** 构建或集成一组针对沙箱的对抗任务：fork 炸弹、网络渗出尝试、文件系统逃逸、LLM 编写的 shell 元字符。确认所有任务都被阻止。撰写发现报告。

9. **可重复性。** 每篇论文都附带其树搜索追踪 JSON、种子、W&B 运行链接、沙箱配置和端到端重现的 README。

## 交付它

`outputs/skill-ai-scientist.md` 是交付物。给定种子想法 + 领域 + 30 美元预算，它运行完整管道并输出可评审的论文加可重复性包。

| 权重 | 标准 | 衡量方式 |
|:---:|------|----------|
| 25 | 论文质量 | 对比已发表研讨会论文的盲审评分 |
| 20 | 实验严谨性 | 基线、种子、消融；每个声明都有结果表中的单元格支持 |
| 20 | 成本和计算纪律 | 强制执行 30 美元/篇上限，Langfuse 追踪 |
| 20 | 安全性 | 沙箱红队测试通过；网络策略和终止开关已验证 |
| 15 | 可重复性 | 单命令重新运行，使用相同种子重现论文 |
| **100** | | |

## 练习

1. 在相同领域针对三个不同的种子想法运行管道。比较树搜索的哪些部分重叠。识别重复浪费的计算。

2. 在估计超过 5 美元的节点执行前添加人工在环门控。测量总成本下降多少。

3. 将审稿委员会替换为单个评委。在已知不良论文的保留集上测量误接受率。

4. 引入网络渗出红队测试：智能体编写尝试 `curl` 外部地址的代码。确认 `--network=none` 策略阻止了它。记录尝试。

5. 将你的树搜索与平坦随机基线（相同预算，无扩展策略）进行比较。报告新颖性 × 质量的增益。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| 树搜索 | "AB-MCTS 风格扩展" | 使用新颖性×质量×预算分数对实验节点进行最佳优先探索 |
| 沙箱 | "实验隔离" | 无网络、有界 CPU/内存、固定种子、只读输入的容器 |
| 视觉批评 | "渲染后阅读" | 将论文编译为 PDF，将 PDF 反馈给 VLM 进行布局和声明-证据批评 |
| 审稿委员会 | "自动化同行评审" | 多位 LLM 评委使用 NeurIPS 评分标准对论文进行评分；加权聚合控制管道 |
| 新颖性分数 | "这是新的吗？" | 惩罚与 50 篇论文文献缓存接近程度的启发式方法 |
| 成本上限 | "$ 预算" | 每篇论文总支出的硬上限；Langfuse 计数器 + 运行前估计 |
| 红队 | "沙箱逃逸审计" | 如果策略错误，会逃逸沙箱的对抗任务 |
